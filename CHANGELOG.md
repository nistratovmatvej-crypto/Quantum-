# Changelog

## Quantum Alpha 0.1.2 — visual identity refresh

- Replaced the five-point star with the concentric Quantum mark based on the supplied logo.
- Introduced an Atlantic teal, warm porcelain and cyan palette.
- Refined home screen hierarchy, assistant hero area and system status cards.
- Reworked settings into clearer grouped native cards.
- Added a visual identity and design principles document.

### Scope note
This release is a visual refresh only. It does not add microphone capture, speech recognition, AI inference, voice output, or device-control execution.
