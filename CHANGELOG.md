# Changelog

## Quantum Alpha 0.2.0 — first usable Android shell

- Added explicit runtime microphone permission flow.
- Connected Android SpeechRecognizer for real speech-to-text.
- Added a top-centred expandable in-app Dynamic Island control.
- Added first-launch local profile onboarding.
- Added Meteor / Comet / Nova local-tier selector with saved preference.
- Added Supernova Pro plan preview and clearly disabled purchase action until Play Billing is configured.
- Fixed a unit-test compile mismatch and expanded microphone lifecycle coverage.
- Preserved the Quantum concentric mark and Atlantic teal / porcelain design system.

### Limitations
No conversational AI, bundled local model, cloud account, Play Billing purchase flow, text-to-speech, macros or device-control execution is included yet. The profile is local-only. The Dynamic Island is in-app, not a system-wide overlay.
