# Quantum — Development Roadmap

All pre-release milestones use the **Quantum Alpha 0.x** naming sequence.

## Quantum Alpha 0.1 — Foundation
- [x] Establish product baseline and technical architecture.
- [x] Define assistant behavior, privacy principles, and visual identity.
- [ ] Create Android Studio project and Compose design system.
- [ ] Build static home screen and settings navigation.
- [ ] Prototype floating star and horizontal panel states.

## Quantum Alpha 0.2 — Voice interaction
- [ ] Microphone permission and explicit start/stop.
- [ ] Speech-to-text adapter.
- [ ] Text-to-speech adapter and playback controls.
- [ ] 15-second silence timeout.
- [ ] Conversation UI and interruption handling.

## Quantum Alpha 0.3 — Assistant core
- [ ] Conversation orchestration.
- [ ] Cloud provider abstraction.
- [ ] Local command parser and offline fallback.
- [ ] Error, timeout, and network-state handling.

## Quantum Alpha 0.4 — Device actions
- [ ] Typed action registry.
- [ ] Confirmation UI and action audit trail.
- [ ] Safe app launching and supported Android intents.
- [ ] Additional actions only where Android APIs permit them.

## Quantum Alpha 0.5 — Memory
- [ ] Four memory modes.
- [ ] History and long-term memory separation.
- [ ] Review, edit, export, and delete controls.

## Quantum Alpha 0.6 — Voice library
- [ ] Voice catalog and licensing metadata.
- [ ] Preview and selection.
- [ ] Multi-item download queue.
- [ ] Pause/resume, retry, cancel, integrity checks.

## Quantum Alpha 0.7 — Local model tiers
- [ ] Runtime abstraction.
- [ ] Meteor, Comet, Nova model evaluation.
- [ ] Device capability recommendation.
- [ ] Offline command coverage and performance tests.

## Quantum Alpha 0.8 — Supernova
- [ ] Google Play Billing integration.
- [ ] Monthly and annual plans.
- [ ] Server-side entitlement and cloud quota handling.
- [ ] Pro voice catalog access.

## Quantum Alpha 0.9 — Stabilization
- [ ] Battery, thermal, memory and accessibility testing.
- [ ] Privacy and permission review.
- [ ] Crash and lifecycle testing across Android versions.
- [ ] Release candidate and documentation.

## Global release
The global release version is assigned only after the Alpha sequence is complete and release criteria are met.
